Hide local referrers?

Enabling this hides referrers from the website's own hostnames and aliases. It is enabled by default. Requests still count toward page views, visitors and bandwidth. Disabling it includes local referrers again.

The filter covers the first 32 distinct DNS names or wildcard subdomains. If there are more names, reports still update and warn that some local referrers may appear. Changes apply to the next report update.
