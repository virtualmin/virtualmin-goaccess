Include rotated and gzip-compressed logs?

Enabling this includes numbered and dated rotations of the website's access log, including gzip files. This is enabled by default. Disabling it reads only the current log, so older traffic disappears from the next report.

Only rotations belonging to the configured access log are included. If the number of files exceeds the administrator's limit, the update fails and keeps the previous report. Changes apply to the next report update. Log files are not changed or deleted.
