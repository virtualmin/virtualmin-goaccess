GeoIP2 ASN database

A MaxMind GeoLite2 ASN .mmdb database adds the network number and organization associated with visitor IP addresses to reports. Use the full path to the installed file. It works on its own or alongside a Country or City database. Leaving this blank omits network lookups.

GeoIP reporting requires GoAccess 1.7 or later built with GeoIP2 support. Each domain owner must be able to read the file and access its parent directories. Download and update the database separately. Changes apply to the next report update.
