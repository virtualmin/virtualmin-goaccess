GeoIP2 City database

A MaxMind GeoIP2 or GeoLite2 City .mmdb database adds visitor country and city details to reports and takes precedence over a Country database. Use the full path to the installed file. City details are listed for individual visitor IP addresses. IP anonymization is enabled by default and can make these details less accurate or unavailable. Leaving this blank omits city lookups. Country details are still included if a Country database is configured.

GeoIP reporting requires GoAccess 1.7 or later built with GeoIP2 support. Each domain owner must be able to read the file and access its parent directories. Download and update the database separately. Changes apply to the next report update.
