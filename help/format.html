Access log format

The parser format must match the website's access log. Combined format is the default. Common format has no referrer or user-agent fields, so those details are unavailable in the report. Virtual-host combined format also includes the website name in each log entry.

Built-in formats ignore custom log, date and time patterns. Custom parsing requires all three patterns to match the log. Changes apply to the next report update and do not change how the web server writes its logs.
